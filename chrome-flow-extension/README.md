# Flow Product Creator Chrome Extension

This extension scrapes product details from the active page and helps prepare a prompt for Google Flow.

## Features
- Scrape title, description, price, image URL and page URL from product pages
- Build a prompt for Flow image/video generation
- Open Flow in a new tab
- Inject a script to click Flow's `New project` button

## Install
1. Open `chrome://extensions`
2. Enable Developer mode
3. Click `Load unpacked`
4. Select the `chrome-flow-extension` folder

## Usage
1. Open a product page
2. Click the extension icon
3. Press `Scrape product`
4. Press `Copy Flow prompt`
5. Open Flow and create a project manually or use `Click New project`
